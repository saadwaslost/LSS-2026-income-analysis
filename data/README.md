# Data

Source: Becker, B. & Kohavi, R. (1996). Adult [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5XW20 (CC BY 4.0).

The script expects the CSV with a header row and these column names: age, workclass, fnlwgt, education, educational-num, marital-status, occupation, relationship, race, gender, capital-gain, capital-loss, hours-per-week, native-country, income. The files on the UCI page have no header and name two columns differently (education-num, sex), so add the header with these names first.
